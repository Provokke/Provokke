# Hi, I'm Provokke

I'm a software engineer based in Sydney, Australia. I work across the stack: smart contracts and wallet flows, APIs and frontends, and the pipelines and cloud infrastructure that ship them. If I do something more than once, I try to automate it.

## What I work with

- Web3: wallet and payment flows, Bitcoin and ecash, smart contracts (Solidity, Foundry, viem)
- Cloud and DevOps: AWS, Terraform, Docker, Kubernetes, GitHub Actions
- Web: TypeScript, React, Next.js, Node.js, Python
- Game mods: Lua scripts and frameworks for FiveM and RedM

## Projects

- [blockwarden](https://github.com/Provokke/blockwarden): self-hosted, serverless EVM event monitoring on AWS. Durable records from finalised blocks, fast provisional alerts, a lagging-node guard and property-tested scanning, deployed with Terraform.
- [tether-m4l](https://github.com/Provokke/tether-m4l): bridge that streams an Ableton Live Set's state to a WebSocket server and takes commands back. Has a Node relay server, a browser dashboard, tests, CI and tagged releases.
- [shopify-admin-app](https://github.com/Provokke/shopify-admin-app): embedded Shopify admin app skeleton with OAuth, a cost-aware GraphQL client, bulk operations and idempotent webhooks. Tests and demo run offline.
- [serverless-api-terraform](https://github.com/Provokke/serverless-api-terraform): serverless items API on AWS with Terraform modules, least-privilege IAM and offline unit tests.
- [catalogue-sync-pipeline](https://github.com/Provokke/catalogue-sync-pipeline): supplier feed sync (CSV, JSON, HTML) with diffing, batched sync with checkpoint resume and a fetcher that respects robots.txt.
- [web3-checkout-demo](https://github.com/Provokke/web3-checkout-demo): Solidity escrow checkout with Foundry fuzz tests and a TypeScript pay client that runs against a local anvil node. Unaudited and never deployed.
- [fivem-redm-toolkit](https://github.com/Provokke/fivem-redm-toolkit): Lua framework bridge for ESX, QBCore and Qbox with a NUI sample. Specs and demo run offline; it has never been run on a live FXServer.
