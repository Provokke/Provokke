## 🚀 About Me

I'm a multi-disciplinary engineer working across the whole stack: from smart contracts and wallets, through APIs and frontends, down to the pipelines and cloud infrastructure that ship and run them. My philosophy is simple: if a task is repeated more than once, it should be automated.

### 🎯 What I Do

- ⛓️ **Blockchain & Web3** - Wallet and payment flows, Bitcoin/ecash protocols, smart contract integration
- 🔧 **DevOps** - CI/CD pipelines, containerisation, infrastructure as code, monitoring
- ☁️ **Cloud & AWS** - Designing, deploying and cost-tuning cloud infrastructure
- 🌐 **Full-Stack** - TypeScript, React/Next.js frontends and Node.js/Python backends
- ⚡ **Automation** - Agentic tooling, workflow automation and developer productivity tools
- 🔌 **Real-time Systems** - WebSocket services, event pipelines and live dashboards
- 🎮 **Game Development** - FiveM/RedM modifications, scripts, and frameworks

### 💡 Current Focus

- ⛓️ Building open source Web3 tooling and contributing to Bitcoin/ecash projects
- ☁️ Production-grade AWS infrastructure with Terraform
- 🔧 Kubernetes operations and platform engineering
- 🤖 AI-assisted developer tooling (MCP servers, code-review and audit pipelines)
